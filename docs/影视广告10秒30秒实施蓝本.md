# QTVQ 影视广告 10 秒 / 30 秒实施蓝本（V1.0）

- 编制日期：2026-10-30
- 上游依据：《影视广告五步推演终态结论》（同日）+《再改造技术实施书》P3 增长引擎
- 执行顺序铁律：**40 条图文内容先行发布 → 10 秒 A/B 小流量 → 胜出版本与 30 秒片扩量**。本蓝本产出物是渠道素材，全部进入 `ch` 归因体系，不做无指标位的品牌片。
- 时长口径：原 60 秒方案调整为 **30 秒**——信息流完播率随时长衰减，30 秒是付费深度素材的最优上限；60 秒版留作视频号/主页常驻，不进付费投放。

## 1. 总体技术规格（两支片子共用）

| 项 | 规格 |
|----|------|
| 画幅/分辨率 | 竖屏 9:16，1080×1920，30fps，H.264，码率 ≥ 10 Mbps |
| 响度 | 混音目标 -14 LUFS（integrated），真峰值 ≤ -1 dBTP |
| 安全区 | 关键信息（字幕/Logo/CTA）保持在中央区域：上 12%、下 22%、右侧 12% 预留平台 UI；**终渲染前按平台最新规范模板复核一次**（平台规范会改，此条为生产标准，非免检项） |
| 字幕 | 硬字幕全程覆盖静音观看；思源黑体或阿里巴巴普惠体（免费商用，**禁用微软雅黑等未授权字体**）；单行 ≤ 12 字，主字幕 ≥ 64px，白字深色描边，位于画面 72% 高度 |
| 色彩 | 底色：暮色丛林（深青绿阴影 + 暖金残光）；光源与特效：`#FF6B81` → `#6C5CE7` 粉紫辉光；全片 LUT 统一，Logo 段用品牌渐变原色 |
| 生成内容标识 | AI 生成镜头按《人工智能生成合成内容标识办法》在平台侧勾选「AI 生成」声明并保留显式标识位 |
| 帧率纪律 | 生成素材统一 30fps 补帧到目标，不混用 24/25/30fps |

**AI 生成通用提示词基底**（可灵/即梦/Veo 级工具，每个镜头单独生成 4–8 秒，多抽卡选优）：

> photorealistic dense forest at dusk, volumetric Tyndall light shafts through canopy, deep teal-green shadows, glowing bioluminescent particles in magenta (#FF6B81) and violet (#6C5CE7), cinematic 35mm, shallow depth of field, slow dolly

**负面提示词（每条生成必带）**：no animals, no human faces, no characters, no text, no logos, no watermarks——杜绝任何与《奇幻森林》角色相似的具象生物，杜绝生成字体内嵌（文字一律后期上）。

## 2. 10 秒片蓝本（A/B 两版，共用品牌尾）

**职能**：信息流钩子，只负责「好奇与识别」。声音设计为主，无旁白，字幕承载全部信息。
**A/B 结构**：前 7 秒两版独立（隔离变量＝钩子风格），**7–10 秒共用同一品牌尾**（降低制作成本、保证品牌一致性、让对比只发生在钩子上）。

## 3. 30 秒片蓝本（信任片）

**职能**：代入与行动，锚定「激活」（完善资料 / 首次提问）。结构与 40 条内容矩阵同源：真实案例开场。
**案例依据**：库内真实案例「红包陷阱：转账备注写借款」（网恋场景，见 `apps/qtvq-uni/src/data/pitfalls-sample.json`），做场景还原改编。

### 3.1 分镜与旁白总表

| 段 | 时码 | 画面 | 旁白（VO） | 字幕/包装 |
|----|------|------|-----------|----------|
| ① 真实案例钩子 | 0–4.5s | 聊天记录 UI 动画还原：对方消息「转我 3 万，备注写借款，这样有保障」→ 转账界面金额键入 → 屏幕渐暗 | 无 VO（文本驱动 + 键盘音、消息音） | 转账备注「借款」二字 `#FF6B81` 高亮；段末黑屏字幕「三个月后，这三万成了说不清的债。」 |
| ② 隐喻桥 | 4.5–11s | 暮色丛林空镜 ×2：丁达尔光穿过林隙；一个人影（剪影，不露脸）站在分岔小径，一边路牌泛紫光一边路牌缠荆棘 | 「感情的丛林里，坑从来不会提前打招呼。」（16 字 ≈ 4s） | 同步硬字幕 |
| ③ 产品演示 | 11–21s | 真实产品录屏（手机框内）：输入困惑 → 避坑诊断报告生成 → 三段结构滚动（风险点 / 对照案例 / 行动清单） | 「把你的困惑交给 Q 问——五十条真实案例训练出的避坑诊断，十分钟给你一份行动清单。」（37 字 ≈ 8s） | 录屏关键处加圈注动效；角标常驻「24 小时 5 次免费提问」 |
| ④ 信任层 | 21–26.5s | 三行资质字幕逐条落下 + 案例库翻页动效 | 「我们不承诺脱单，只帮你看清脚下的路。」（16 字 ≈ 4s） | 「50 条真实案例 · 经营许可齐全 · 只面向 18–30 岁」 |
| ⑤ 共用品牌尾 + CTA | 26.5–30s | 与 10 秒片同一品牌尾资产复用 | 「今晚，来问第一句。」（8 字 ≈ 2s） | 主：「首次提问免费」副：「搜索 **Q问**」 |

**VO 总字数 77 字，落在约 18 秒语音段内，语速 4–5 字/秒，留呼吸位。**
**配乐**：情绪曲线「悬念→释然→笃定」，买断授权单轨，-18 LUFS 垫底不压 VO。

### 3.2 制作要点

1. **录屏采集**：真机录屏（1080×1920），走查真实流程，禁止设计假 UI；录屏外套手机壳 mock，品牌描边。
2. **案例还原**：聊天 UI 用产品内同款样式重排，姓名头像打码脱敏，片尾标注「根据真实案例库改编」。
3. **素材衍生**：同一时间线剪出 **15 秒剪辑版**（①+③后半+⑤）作信息流第二测试位；30 秒版部署在 `land.html` 顶部（静音自动播放 + 硬字幕）、小程序「避坑」页头、视频号主页。
4. **返工预留**：AI 镜头按 1.5 倍工时预留（角色一致性不适用于本片——全片无具象角色，只有空镜与录屏，返工风险主要在光效一致性）。

## 6. 合规审查清单（送审前逐条勾选）

### 6.1 IP 红线（对照《奇幻森林》）
- [ ] 全片无任何具象动物角色、人物角色与已知名角色形象相似
- [ ] 无迪士尼影片角色名、台词、配乐旋律（含改编哼唱）、标志性桥段
- [ ] 创意文案与素材中不出现「奇幻森林」「迪士尼」字样——对外表述只用「暮色丛林 / 感情的丛林」

### 6.2 广告法话术
- [ ] 无效果承诺类表述（禁用：保证、百分百、必脱单、挽回神器、治愈、告别单身）
- [ ] 「我们不承诺脱单，只帮你看清脚下的路」——陈述功能边界，保留
- [ ] 价格与权益表述与产品实际一致（24 小时 5 次免费提问、首单 ¥4.9 等数字与线上一致，不许夸大）
- [ ] 全片维持 18–30 岁成年用户定位声明，无任何面向未成年人的暗示

### 6.3 平台与版权
- [ ] 抖音/小红书交友类目报白通过（前置条件 #2）
- [ ] AI 生成内容平台声明 + 显式标识位已留
- [ ] 音乐买断凭证、字体授权（思源黑体/阿里巴巴普惠体）、演员肖像授权书归档

## 7. 执行记录

### 7.1 10s-A v1 交付（2026-10-30）

**成片**：`media/ads/10s/qtvq-10s-A-v1.mp4` — 10.00s / 1080×1920 / H.264 High / 30fps / 10,003 kb/s（CBR）/ AAC 192k 立体声 / 12.5MB。

**规格对照**：时长 ✅ 10.00s ｜ 分辨率/帧率 ✅ ｜ 码率 ✅ 10,003 kb/s（≥10M 达标）｜ 安全区 ✅（字幕 72% 高度、AI 标识 88%）｜ 字幕 ✅ HarmonyOS Sans SC（免费商用）双描边 ｜ 品牌色 ✅ 全部光效取 `#FF6B81`/`#6C5CE7` ｜ AI 标识位 ✅ 左下「内容由 AI 辅助生成」｜ IP 红线 ✅ 全片无具象动物/角色/迪士尼元素。

**工序**：`gen-frames.mjs`（SVG 分镜逐帧渲染，resvg，300 帧）+ `gen-audio.mjs`（音效设计程序化合成，44.1kHz/16bit）+ ffmpeg 合成（`nal-hrd=cbr` 达标 10M）。质检：五个关键帧目检两轮（第一轮修 S1 太黑、S2 主体穿字幕、S4 无运动感三处，第二轮复检通过）+ 成片解帧终检无色带。

**规格偏离记录（1 项）**：蓝本 §2.1 的 AI 生成 photoreal 底板本机无法生成，本版以**程序化动效（motion-graphics）**完成全部五段——它同时是**时码/音效/字幕母版**：后续用可灵/Veo 类工具逐镜替换背景底板时，节奏、声音、字幕、安全区全部不动。版本 B（真人实拍）需选角与拍摄，超出本机能力，未制作。

**重渲染方式**：`cd media/ads/10s && node gen-frames.mjs 0 299 && node gen-audio.mjs`，再用 §7.1 的 ffmpeg 参数合成。种子固定（20261030），结果可复现。
