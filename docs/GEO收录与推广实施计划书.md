## 四、G3 内容层引用力（随 P3 内容矩阵同步）

**50 条案例的 GEO 化改写模板**（每条）：
1. **问题句**（用户真实问法，如"异地恋该不该继续"）——AI 引擎按问题匹配；
2. **结论句**（一句话可直接被引用的答案，含数据点如"72% 的案例在 3 个月内出现同类信号"——数据来自案例库统计）；
3. **行动清单**（3 步，可执行）；
4. **来源声明**（"根据 Q问 50 条真实案例库第 N 条"——权威与可验证）。

**落地位置**：pitfalls.html 每案例独立锚点页（`/pitfalls.html#case-N`）+ FAQ 12 条页 + advice.html 结构化呈现。

**红线不变**：18–30 限定表述、不承诺效果、数据全部来自真实案例库（不编造统计）。

## 七、不做的事（明确排除）

1. **不做关键词堆砌/隐形文字**——违反搜索引擎规则，封禁风险大于收益；
2. **不买外链**——同上；
3. **不做涉政内容 SEO**——词表刻意不含涉政（合规红线）；
4. **不追求 llms.txt 的过度形式**——llms.txt 是索引，内容引用力在页面本身。
